### 主题现在的确切语义（别按旧理解改）

- 首帧脚本在 `getHtmlLayout` 的 `<head>`（`src/ui/templates.js`，与 `</style>` 同一行）：读 `localStorage.theme`；**没有保存值就取 `matchMedia('(prefers-color-scheme: dark)')`**，同时写 `class="dark"` 与 `data-theme`（防暗色闪白）。
- 监听该 media query 的 `change`：**用户没显式选过就跟着系统变**；点过切换按钮后写入 `localStorage.theme`，此后以保存值为准。
- 切换按钮由各页自己放（首页 `.public-nav-actions`、后台 `.sidebar-header`），**逻辑只在布局里定义一次**，首页模板里不再有 `applyTheme`。
- 后台按钮：`#theme-toggle`，`44×44`，`margin: 0`，`flex: 0 0 auto`，图标随状态换 `fa-moon`/`fa-sun`，`aria-label` 随之变「切换到深色/浅色主题」。
- 实测（1440/1024/900/768/390 五档）：标题与按钮中线差 `0.00–0.01px`；无横向滚动；清空 localStorage 首帧 = 系统偏好，点击后 `stored='dark'`、`body #121212`，重载保持。

## 3. 必须知道的（增量部分，旧的见上一份交接）

1. **测试断言的是源码形状**，不是行为。改标记前先 `grep` 测试，例：`test/templates-escape.test.ts` 里断言 `#theme-toggle {…}` 规则体含 `margin: 0;`、`.sidebar-header {` 含 `display: flex;`。改 CSS 结构会挂。
2. **describe 作用域隔离**：`baseSettings` 定义在「getDashboardPage 仪表盘转义」那个 `describe` 内，别的 `describe` 用不到（本轮因此挂过一次 `ReferenceError`）。新测试块自己备一份最小 settings 字面量。
3. **`bsk emulate` 切宽度后，`innerWidth` 会先变、媒体查询后生效**，曾出现「同一宽度两次读数侧栏 250px vs 200px」。判断断点行为前先 `navigate` + 等 1.5s，别在 resize 当下取样。
4. **用户 Chrome 装的主题扩展会钉死 `data-theme="light"`**（`html` 带 `tongyi-design-pc` 类）。所以探针里 `dataset.theme` 可能被它改回去：**判定以 `classList.contains('dark')` + 实际背景色为准**，不要以 `data-theme` 属性为准。
5. `Start-Job` 起的 `pnpm dev` 会随那次 `pwsh` 调用结束而死（表现为 `ERR_CONNECTION_REFUSED`）。要用 harness 的后台作业（`run_in_background: true`）跑 dev server。
6. 端口会漂：`8787` 被占时 wrangler 自动 +1（本轮是 `8788`，更早是 `12733`）。**脚本里不要写死端口**，先看 `pnpm dev` 输出，`.scratch/verify-theme-align.ps1`、`.scratch/theme-check.ps1` 都已参数化（`-Port`）。
