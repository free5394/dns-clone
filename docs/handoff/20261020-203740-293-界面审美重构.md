## 4. 改这个文件前必须知道的四个技术事实

1. **Pico v2 的浅色令牌写在 `:root:not([data-theme="dark"])`**（特异性 0,2,0），会压过裸 `:root`（0,1,0）——不管源序。所以本项目的浅色块用 `:root, :root[data-theme="light"]`，暗色块用 `:root[data-theme="dark"], :root.dark`（同为 0,2,0，暗色排后胜出）。任何新增令牌都要放对块。
2. **CSS 全在 `getHtmlLayout(title, content)` 里**（`src/ui/templates.js:23-340`）。`getPublicHomepage` / `getDashboardPage` 只返回主体 HTML。写 CSS 断言必须自己拼：`getHtmlLayout("x", getPublicHomepage(...))`。
3. **首帧主题脚本在 `getHtmlLayout` 的 `<head>`**（`:340`，与 `</style>` 同一行），它同时设 `data-theme` 与 `.dark`。后台没有切换按钮，靠它跟随 localStorage。
4. **选择器契约**：单条同步按钮靠 `#domain-card-${id} .card-actions button:first-child` 命中，所以 `.card-actions` 里的第一个按钮必须始终是「同步」。改行结构时别动这个顺序。
